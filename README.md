# Conquer the Overlook 2025 Race Analysis

This project analysis results from the 2025 Conquer the Overlook 5k using Python.

## Project Goals

- Extract race results from a multi-page PDF
- Clean and structure the data using pandas
- Create analysis ready variables
- Generate descriptive statistics
- Perform statistical inference
- Create visualizations of race performance


## Tools
- Python
- pandas
- pdfplumber
- JupyterLab
